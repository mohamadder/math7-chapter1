ریاضی هفتم - فصل ۱ (نسخه مولتی‌مدیا)
==========================================

این چیه؟
فصل اول (راهبردهای حل مسئله) با معلم کارتونی ۲D متحرک، صدای فارسی، تخته‌ی کلاس با انیمیشن، مداد رنگی و چوب کبریت، و سؤال تعاملی بعد از هر درس. ۶ درس دارد.

--------------------------------------------------
روش ۱ (سریع‌ترین) - ریپوی قبلی که از جمینای داری
--------------------------------------------------
فقط ۲ فایل عوض می‌شه:

۱) توی گیت‌هاب ریپوی اپ رو باز کن، فایل MainActivity.kt رو پیدا کن
   (مسیرش معمولاً app/src/main/java/ir/math7/learning/MainActivity.kt)
   ← آیکون مداد (Edit) ← همه‌ی متن رو پاک کن ← متن فایل جدید MainActivity.kt رو بچسبون ← Commit changes
   (مسیر فایل رو عوض نکن؛ فقط محتواش رو عوض کن)

۲) فایل app/src/main/AndroidManifest.xml رو باز کن ← همه‌ی محتواش رو با فایل AndroidManifest.xml جدید عوض کن ← Commit.
   (این فایل جدید یه بخش queries داره که برای کار کردن صدا لازمه.)

۳) برو تب Actions ← منتظر بمون بیلد تموم شه (تیک سبز) ← روی آخرین Run بزن ← پایین صفحه Artifacts ← APK رو دانلود کن و نصب کن.

اگه بیلد خطای قرمز داد: متن خطا رو کپی کن و برای من بفرست.

--------------------------------------------------
روش ۲ - ریپوی تازه (اگه ریپوی قبلی نداری)
--------------------------------------------------
توی ریپوی جدید این فایل‌ها رو با همین مسیرها بساز (Add file ← Create new file، مسیر رو توی کادر اسم تایپ کن):
  settings.gradle.kts
  build.gradle.kts
  gradle.properties
  app/build.gradle.kts
  app/src/main/AndroidManifest.xml
  app/src/main/java/ir/math7/learning/MainActivity.kt
  .github/workflows/build.yml
محتوای هر کدوم توی پوشه full-project داخل فایل zip هست. بعد از Commit، مثل مرحله ۳ بالا APK رو از Actions بگیر.

--------------------------------------------------
صدای فارسی
--------------------------------------------------
اپ دو راه برای صدا داره:
۱) فایل صوتی ضبط‌شده (بهترین کیفیت): فایل mp3 رو با این اسم‌ها توی پوشه app/src/main/res/raw/ بذار:
     l0s0.mp3  = درس ۱، صحنه ۱     l0s1.mp3 = درس ۱، صحنه ۲  ...
     l0q.mp3   = سؤال پایانی درس ۱
     l1s0.mp3  = درس ۲، صحنه ۱  و همین‌طور تا l5...
   (حرف l کوچک + شماره‌ی درس از صفر + s + شماره‌ی صحنه از صفر)
۲) اگه فایل صوتی نباشه، از موتور صدای خود گوشی (TTS) استفاده می‌کنه. اگه گوشی صدای فارسی نداره، اپ پیام می‌ده و فقط انیمیشن و زیرنویس کار می‌کنه.
